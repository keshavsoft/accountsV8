⚡ Project Setup Workflow

Step 1 — Clone Repository

Clone the project from GitHub.

git clone https://github.com/keshavsoft/accountsV8

Step 2 — Open Project in VS Code

cd accountsV8 code .

Step 3 — Generate Data Folder

Run schema generator file to automatically create:

  • Data folder
  • Schema-based JSON files
  • Initial data structure
node Scripts/generateDataFromSchema.js

Step 4 — Install Dependencies

npm install

Step 5 — Start Server

npm start

Step 6 — Open Application

After server starts, terminal shows local server URL.

http://localhost:3000

Step 7 — Check Latest Public Version

Open latest version folder inside:

Public/

Example:

Public/V1 - Public/V2 - Public/V8

Latest version folder contains active UI files.
